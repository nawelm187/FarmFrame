# Imágenes de personajes (NPC) que usa FarmFrame

La web usa estos personajes. Cada uno se muestra con su retrato si existe el archivo en `src/assets/npc/`
(.png, .webp o .jpg). Si no existe, FarmFrame intenta pedir el retrato a la wiki de Warframe; si tampoco llega, muestra una silueta con el nombre.

El nombre del archivo es el nombre del personaje en minúsculas, con guiones.

| Personaje | Archivo | Dónde aparece |
|---|---|---|
| Baro Ki'Teer | `baro-ki-teer.png` | Home, Planner, Rotations (Void Trader) |
| Varzia | `varzia.png` | Rotations (Prime Resurgence) |
| Teshin | `teshin.png` | Rotations y Planner (Steel Path Honors) |
| Darvo | `darvo.png` | Rotations (oferta diaria) |
| Cephalon Simaris | `cephalon-simaris.png` | Rotations (Synthesis) |
| Nora Night | `nora-night.png` | Planner (Nightwave) |
| Archon Amar | `archon-amar.png` | Planner (Archon Hunt, según la semana) |
| Archon Nira | `archon-nira.png` | Planner (Archon Hunt, según la semana) |
| Archon Boreal | `archon-boreal.png` | Planner (Archon Hunt, según la semana) |

Tamaño sugerido: cuadrado, 256×256 o más. Usá imágenes que tengas derecho a usar (por ejemplo, capturas propias del juego).
