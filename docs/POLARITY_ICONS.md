# Iconos de polaridad

FarmFrame muestra la polaridad de cada mod y de cada slot de build con la imagen original, si la subís a `src/assets/polarity/`.
Formato: .png, .webp o .svg. El nombre del archivo es el nombre de la polaridad en minúsculas.

| Archivo | Polaridad |
|---|---|
| `madurai.png` | Madurai |
| `vazarin.png` | Vazarin |
| `naramon.png` | Naramon |
| `zenurik.png` | Zenurik |
| `unairu.png` | Unairu |
| `penjaga.png` | Penjaga |
| `umbra.png` | Umbra |
| `aura.png` | Aura |
| `koneksi.png` | Koneksi (Archwing y Railjack) |
| `any.png` | Omni / universal |

Tamaño sugerido: cuadrado, 64×64 o más, fondo transparente.
Mientras falte un archivo, la web muestra un marcador simple con las 3 primeras letras (por ejemplo "mad"), no un símbolo inventado.
