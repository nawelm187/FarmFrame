Portraits of vendors and characters go in this folder as .png, .webp or .jpg files.
The file name is the character name in lowercase with dashes:
baro-ki-teer, varzia, teshin, palladino, acrithis, darvo, cephalon-simaris, nora-night
Archon Hunt shows the boss named by the data, for example archon-amar, archon-nira, archon-boreal.
A missing image is shown as a neutral silhouette with the name underneath.
